# Planches des polices (26 novembre 2026)

Demande de Raph : la police lisse actuelle (Palatino) « fait un peu trop IA » ; un panel varié, posé sur le menu Arène
et sur la fin d'un duel, pour choisir celle du jeu (et d'abord du mode Arène).

- `polices_1_pixels.png` : 1 à 9, pixels nets (la police dessinée du jeu, Silkscreen, Pixelify Sans, Jersey 10, Micro 5,
  VT323, DotGothic16, Jacquard 12, Handjet) ;
- `polices_2_japon.png` : 10 à 17, l'actuelle et l'esprit japonais (Shippori Mincho, Zen Antique, Sawarabi Mincho,
  Kaisei Decol, Yuji Boku, Yuji Syuku, Yusei Magic) ;
- `polices_3_simples.png` : 18 à 24, simples, arrondies, livres (Zen Maru Gothic, Kiwi Maru, M PLUS Rounded 1c,
  IM Fell Double Pica, Alegreya SC, Almendra, Spectral).

Toutes sous licence libre (SIL OFL, Google Fonts). Refaire : télécharger les .ttf et les deux décors dans
`tools/maquettes/polices/`, servir le dépôt en http, puis `node tools/maquettes/polices.cjs` (`tools/maquettes/polices.html`).
